# riir

Short links for the code references in *Rewrite It in Rust* (Andrew Gauger,
Packt). Each printed reference, such as `andygauge.github.io/riir/3a`,
redirects to the companion code it names in
[PacktPublishing/Rewrite-it-in-Rust_Andrew-Gauger](https://github.com/PacktPublishing/Rewrite-it-in-Rust_Andrew-Gauger).

The pages are generated from the book's manuscript tooling
(`docx site`); don't edit them by hand. The full list is at
[andygauge.github.io/riir](https://andygauge.github.io/riir/).
